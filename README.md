# Юнит-тесты

> Учебные юнит‑тесты для класса `Burger` (Stellar Burgers).  
> Стек: Java, JUnit 4, Mockito, JaCoCo, Allure.  
> Цель: покрыть класс тестами с использованием моков/стабов и параметризации, достичь 100% покрытия кода.

---
## 🎯 Цель и задачи

Этот проект — учебная практика по написанию юнит‑тестов для бизнес‑логики заказа бургера. В рамках задания требовалось:

- Протестировать класс `Burger`: назначение булочки, добавление/удаление/перемещение ингредиентов, формирование чека и расчёт цены.
- Использовать **Mockito** для изоляции зависимостей: моки `Bun` и `Ingredient` с настройкой стабов на методы `getPrice()`, `getName()`, `getType()`.
- Применить **параметризованные тесты** (`@RunWith(Parameterized.class)`) для проверки расчёта цены в разных сценариях (с ингредиентами и без).
- Добиться **100% покрытия кода** для класса Burger по метрикам JaCoCo.
