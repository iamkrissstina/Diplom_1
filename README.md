# Юнит-тесты

> Учебные юнит‑тесты для класса `Burger` (Stellar Burgers).  
> Стек: Java 11, JUnit 4, Mockito 3.12.4, JaCoCo 0.8.14.
> 
> Цель: покрыть класс тестами с использованием моков/стабов и параметризации, достичь 100% покрытия кода.
---
## ✅ Что уже реализовано

В рамках проекта я:

- **Покрыла класс `Burger` юнит‑тестами** на все ключевые операции: назначение булочки, добавление/удаление/перемещение ингредиентов, формирование чека и расчёт цены.
- **Использовала Mockito** для изоляции зависимостей: создала моки `Bun` и `Ingredient`, настроила стабы на методы `getPrice()`, `getName()`, `getType()`. Это позволило тестировать логику `Burger`, не завися от реализации зависимых классов.
- **Применила параметризацию** (`@RunWith(Parameterized.class)`) для проверки расчёта цены в разных сценариях (с ингредиентами и без). В одном тестовом методе покрыто несколько кейсов — это уменьшило дублирование кода и сделало тесты масштабируемыми.
- **Добилась 100% покрытия кода** по метрикам JaCoCo (по строкам и ветвям) для класса `Burger`.
